# ventroof.es — web

Sitio **estático** (HTML autocontenido) de VENTROOF SYSTEM™.
Propiedad: Paneles y Revestimientos, SCP.

## Cómo funciona el despliegue (una vez conectado a GitHub)
1. Se edita cualquier archivo `.html` de este repositorio.
2. Se guarda el cambio en GitHub (commit).
3. Netlify detecta el cambio y **publica solo** en ventroof.es en ~1 minuto.
   Ya no hay que arrastrar nada a mano.

## Archivos
- `index.html` — portada
- `aviso-legal.html`, `politica-privacidad.html`, `politica-cookies.html` — legales
- `netlify.toml` — config de Netlify (no tocar salvo que se sepa lo que se hace)

## Enlaces salientes
- Menú y botón de portada → https://prescriptor.ventroof.es (Generador de prescripción)
